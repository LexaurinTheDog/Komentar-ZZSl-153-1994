# Komentář k zákonu č. 153/1994 Sb., o zpravodajských službách České republiky

Otevřený komentář k zákonu o zpravodajských službách ČR — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; BIS, ÚZSI a Vojenské zpravodajství, jejich úkoly a řízení, spolupráce a poskytování informací, kontrola zpravodajských služeb včetně orgánu nezávislé kontroly a informace Poslanecké sněmovně.

Konsolidované znění: dokument e-Sbírky `SB-1994-00153_2025-07-01`.
